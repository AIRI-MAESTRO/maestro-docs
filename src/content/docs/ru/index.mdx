## Установка скилла MAESTRO

Скилл даёт вашему агенту инструкции и скрипты для работы с MAESTRO через командную строку. Если у вас есть [uv](https://docs.astral.sh/uv/), выполните команду и выберите своего агента — Claude Code, Codex, Hermes или OpenClaw.

```bash
uvx maestro-install skill
```

Откройте новую сессию агента и попросите: «Используй скилл MAESTRO. Проверь, как запускается CLI, и выполни `doctor --no-probes`». Вы увидите, откуда запускается MAESTRO и какие настройки найдены. Для этой проверки ключ модели не нужен. Для генерации цепочек попросите агента помочь настроить рабочую папку и подключить провайдера модели. [Установка и настройка скилла](care/skill/install/)

## Как устроена цепочка

Допустим, нужно извлечь сумму и валюту из чека. Один шаг читает текст, другой извлекает значения, третий проверяет, что сумма — число. **Цепочка** описывает эти шаги и указывает, чей результат нужен каждому из них.

- **CARL** задаёт типы шагов и зависимости между ними. При запуске CARL передаёт результат чтения шагу извлечения, затем передаёт сумму на проверку. **MAGE** может построить такую цепочку по описанию задачи. [Цепочки CARL](carl/getting-started/overview/) · [Генерация с MAGE](mage/getting-started/overview/)
- **IdeaL** хранит предложения о том, что изменить. Например, если цепочка путает скидку с итогом, можно предложить искать сумму рядом со словами «к оплате». При **эволюции** MAESTRO сравнивает варианты на наборе чеков с известными ответами. IdeaL сохраняет сведения о применённой идее и полученных оценках. [Как работает IdeaL](ideal/getting-started/how-it-works/) · [Подготовка примеров в Автобенче](care/autobench/overview/)

## Установка пользовательского интерфейса MAESTRO

Установите Git, [uv](https://docs.astral.sh/uv/), Node.js 24 и pnpm. Затем запустите мастер — он скачает пользовательский интерфейс MAESTRO и соберёт среду выполнения агента.

```bash
uvx maestro-install install
```

После установки убедитесь, что `~/.local/bin` входит в `PATH`, и откройте приложение:

```bash
maestro app
```

### Первый агент в приложении

1. Выберите папку проекта. В **Настройки → Модель чата** укажите провайдера, введите его API-ключ и выберите модель.
2. В новой сессии опишите задачу и приведите пример: «Собери агента, который извлекает сумму и валюту из чека. Для строки „Итого 450 ₽“ ожидаю сумму 450 и валюту RUB».
3. Ответьте на уточнения и подтвердите сборку. Затем попросите запустить агента на другом чеке и проверьте результат в чате.
